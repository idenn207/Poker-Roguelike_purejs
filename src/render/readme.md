### Render 폴더의 책임

**O 포함해야 할 것:**

- ✅ 캐릭터 렌더링
- ✅ 배경, 지형
- ✅ 이펙트, 파티클
- ✅ 애니메이션
- ✅ 조명, 그림자

**X 포함하지 않아야 할 것:**

- ❌ 버튼, 메뉴
- ❌ 다이얼로그
- ❌ HUD
- ❌ 입력 필드

**모두 해당 안 되면 Render 폴더**

- [ ] 클릭/터치 가능한가?
- [ ] 버튼, 입력 필드인가?
- [ ] 화면에 고정되어 있나?
- [ ] 메뉴, 옵션, 설정인가?
- [ ] HUD (체력, 점수 등)인가?
- [ ] 텍스트 입력을 받나?
- [ ] 정보 패널인가?
