주요 화면에대한 설명이야.

1. 로딩화면(로고)

- 맨 처음 로드시 모든 js, css 를 로드하기 때문에 필요한 화면이야.
- 로고를 가운데에 표시해.

2. 로딩화면(로딩)

- 화면과 화면간 전환하기 위해 필요한 화면이야.
- 오른쪽 아래에 'Loading...' 을 표시해.

3. 메뉴화면

- 처음부터, 이어하기, 카드목록, 설정 버튼이 있는 화면이야.
- 처음부터: 게임을 새로 시작해.
- 이어하기: 저장데이터 화면으로 이동해. (저장데이터 화면에서 저장데이터 선택시 그 데이터로 게임을 진행할 수 있어.) (개발 우선순위가 낮은 화면으로 '개발중' 으로 표시해줘.)
- 카드목록: 지금까지 수집한 카드 정보를 확인할 수 있는 화면이야. (개발 우선순위가 낮은 화면으로 '개발중' 으로 표시해줘.)
- 설정: 애니메이션 효과, 오디오, 게임난이도 등을 설정하는 화면이야. (개발 우선순위가 낮은 화면으로 '개발중' 으로 표시해줘.)

4. 스테이지선택화면

- 스테이지를 선택하는 화면이야.
- 선택지: 몬스터(전투화면), 엘리트(전투화면), 보스(전투화면), 회복(회복화면), 보물(보물화면), 상점(보물화면)
- 스테이지를 선택하면 선택한 스테이지의 화면으로 넘어가.

5. 전투화면

- 몬스터, 엘리트, 보스 스테이지의 전투화면이야.
- 몬스터, 엘리트, 보스는 모두 '적(상대)'으로 표현할게.
- 적을 모두 쓰러트리면 보상화면으로 이동해.

6. 보상화면

- 보상화면은 스테이지선택화면과 UI가 동일해.
- 차이점은 '스킵' 버튼이 있는거야.
- 보상을 선택하거나 스킵하면 스테이지선택화면으로 이동해.
