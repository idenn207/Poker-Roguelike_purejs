# 게임 시스템

## 전체 게임 플로우

```plaintext
로고 → 로딩 → 메인 메뉴 → 캐릭터 선택 → 스테이지 선택 → 전투/이벤트 → 보상 → 반복
```

## 카드 시스템

### 카드 구성

- **기본 카드**: 52장 (스페이드, 다이아몬드, 하트, 클럽 × 13장)
- **카드 능력**: 카드당 최대 5개까지 부여 가능
- **발동 조건**: 카드당 1개 조건 부여

### 능력 시스템

#### 능력 타입

- **공격계**: 데미지 증가, 방어 무시, 범위 공격, 화상, 흡혈, 치명타
- **방어계**: 방어 획득, 무효화, 면역, 흡수, 경감
- **회복계**: 회복, 체력 초과, 체력 대출, 상태이상 제거
- **유틸계**: 취약/약화 부여, 카드 생성, 드로우, 버리기
- **버프계**: 위력 증가, 방어 증가, 지속 회복/방어, 반격

#### 조건 타입

- 없음 (기본)
- 특정 족보 이상
- 같은 모양 n개 이상 플레이
- 버렸을 때 발동
- 특정 버프 보유
- 체력 조건

### 카드 강화 메커니즘

1. 전투 보상으로 능력이 부여된 카드 획득 (조건 없음)
2. 상점/휴식에서 추가 능력 부여 시 조건 추가
3. 조건 만족 시 모든 능력 동시 발동

## 전투 시스템

### 전투 진행

1. **플레이어 턴**

   - 10장 드로우
   - 5장 선택하여 플레이 또는 최대 5장 버리기 (턴당 3회)
   - 족보 계산 및 데미지 적용

2. **적 턴**
   - AI가 카드 플레이
   - 플레이어에게 데미지

### 포커 족보

- 로얄 플러시
- 스트레이트 플러시
- 포카드
- 풀하우스
- 플러시
- 스트레이트
- 트리플
- 투페어
- 원페어
- 하이카드

각 족보는 기본 데미지 배율을 가지며, 카드 능력과 유물로 강화 가능

## 스테이지 시스템

### 구성

- **메인 스테이지**: 1~3
- **서브 스테이지**: 각 메인당 1~5
- **총 15개 스테이지**

### 스테이지 타입

- **일반 몬스터**: 1-1 고정, 기타 랜덤
- **엘리트 몬스터**: 높은 보상
- **보스 몬스터**: x-5 고정
- **상점**: 골드로 아이템/카드 구매
- **휴식**: 체력 회복 또는 카드 강화
- **보물**: 유물 획득
- **이벤트**: 선택지 기반 보상/위험

## 보상 시스템

### 전투 보상

- **골드**: 고정 출현
- **카드**: 1~5개 능력 부여된 카드
- **유물**: 족보 강화 효과
- **아이템**: 일회용 전투 도구

### 상점 시스템

- 카드 구매/제거
- 카드 능력 부여/변경
- 조건 변경
- 체력 회복

### 휴식 시스템

- 체력 50% 회복
- 카드 능력 부여 (1~3개 랜덤)
- 조건 제거
