# Entities 폴더

## 역할

게임의 핵심 객체들을 정의하는 엔티티 클래스들입니다.

## 주요 기능

- 게임 객체의 속성 정의
- 객체의 기본 동작 구현
- 데이터와 행동 캡슐화

## 책임

- 엔티티의 속성 관리
- 엔티티별 고유 동작 구현
- 상태 변경 메서드 제공

## 클래스 구조

### Card

개별 카드를 표현하는 클래스입니다.

**주요 속성:**

- `id`: 고유 식별자
- `suit`: 카드 모양 (스페이드, 다이아몬드 등)
- `rank`: 카드 숫자/문자
- `abilities`: 카드 능력 배열 (최대 5개)
- `isSpecial`: 특수 카드 여부
- `rarity`: 희귀도 (능력 개수 기반)

**주요 메서드:**

- `getDisplay()`: 카드 표시 텍스트
- `activateAbilities(context)`: 능력 활성화
- `clone()`: 카드 복사
- `compareTo(other)`: 카드 비교 (정렬용)

### Deck

카드 덱을 관리하는 클래스입니다.

**주요 속성:**

- `drawPile`: 뽑을 카드 더미
- `discardPile`: 버린 카드 더미

**주요 메서드:**

- `initialize()`: 52장 기본 덱 생성
- `shuffle(target)`: 덱 셔플
- `draw(count)`: 카드 드로우
- `discard(cards)`: 카드 버리기
- `reshuffleDiscardPile()`: 버린 카드 재편성

**특징:**

- 드로우 덱이 비면 자동으로 버린 카드 재편성
- 특수 카드 추가 기능
- 조건부 카드 검색

### Player (미구현)

플레이어 캐릭터를 표현하는 클래스입니다.

**계획된 속성:**

- 체력 관리
- 버프/디버프
- 인벤토리
- 스탯

### Enemy (미구현)

적 캐릭터를 표현하는 클래스입니다.

**계획된 속성:**

- AI 패턴
- 의도 표시
- 특수 능력

## 엔티티 생명주기

### Card 생명주기

```plaintext
생성 (Factory)
    ↓
덱에 추가
    ↓
핸드로 드로우
    ↓
플레이/버리기
    ↓
버린 카드 더미
    ↓
재편성 (순환)
```

### Deck 생명주기

```plaintext
초기화 (52장)
    ↓
셔플
    ↓
카드 드로우/버리기 반복
    ↓
재편성
    ↓
전투 종료
```

## 의존성

- **의존하는 것**: CardAbility, CardAbilityCondition
- **의존받는 것**: Factory, Manager

## 설계 원칙

### 1. 엔티티 순수성

- 비즈니스 로직 최소화
- 자기 자신의 데이터만 관리
- 외부 시스템 의존 최소화

### 2. 불변성

- 가능한 한 불변 객체로 설계
- 상태 변경은 메서드를 통해서만

### 3. 캡슐화

- 내부 구현 은닉
- 공개 인터페이스 제공

## 확장 가능성

- 새로운 엔티티 타입 추가 용이
- 카드 능력 시스템 확장 가능
- 상속을 통한 특수 카드 구현 가능
